# Sanatan AI - desktop

Welcome to the Sanatan AI desktop edition. This is a small application built using tauri

## Features
- **Redirect:** Redirects you to Sanatan AI if you are online
- **Offline Support:** Supports offline GUI empowering a PWA like feature.
- **Minimal size:** Very less application size.
- **Eye catching:** Built with eye catching desins and animations.
- **Fast ⚡:** Very fast opening application.
